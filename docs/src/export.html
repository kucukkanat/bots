Export & stickers

Any avatar can be rendered to a file: animated, still, or a whole set of stickers. Frames are drawn offline from a copy of the avatar's simulation, so exporting never stutters the live one, and the exporter's code loads only when you first use it.

bot.export()

```js const gif = await bot.export({ format: 'gif', duration: 2.4, fps: 20 }); const url = URL.createObjectURL(gif); ``` ::table Option | Values | Default `format` | `gif`, `apng`, `webm`, `sprite` (a sheet of frames), `png`, `webp` | `gif` `duration` | seconds of animation | `2` (WebM `3`) `fps` | frames per second | `20` GIF, `25` APNG and sprites, `30` WebM `scale` | pixels per CSS pixel | `2` `background` | a colour, or leave out for transparency | transparent ::end

It resolves to a Blob; a sprite sheet's blob also carries blob.sprite (columns, rows, frames, frameSize, fps). WebM needs MediaRecorder; the others work everywhere the avatar does.

A still frame

```js const png = bot.toDataURL({ scale: 4 }); // the current frame, synchronously ```

Stickers

A single die-cut sticker (512px, white outline, transparent background), or a whole crew as a ZIP of stickers with a crew.json of names and DNA codes:

```js const sticker = await bot.export({ format: 'sticker' }); // PNG; frames: true for an animated APNG import { exportStickers } from '@kucukkanat/bots/export'; const zip = await exportStickers([bot, { type: 'cat', hat: 'party', label: 'Mia' }, 'bot1.…'], { size: 512, outline: true, }); ```

The list takes live avatars, option objects or DNA codes (any other string is used as an identity). Use them as reactions in Slack or Discord, or as a WhatsApp or Telegram sticker pack.
