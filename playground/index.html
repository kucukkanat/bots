Publish to GitHub Pages

Download a ready-to-host index.html with your bot (or your whole crew). It loads the library from a CDN, so it's the only file you need.

  1. Create a new repository on GitHub, e.g. my-bots.
  2. Add file → Upload files and drop in the downloaded index.html. Commit.
  3. Open Settings → Pages, choose Deploy from a branch, branch main, folder / (root), and save.
  4. In a minute your bots are live at https://<you>.github.io/my-bots/.
