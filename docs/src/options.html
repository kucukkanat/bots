Options

Every option works as a JavaScript option in camelCase and as an attribute in kebab-case. Leave one out and you get the default; set one later with bot.set() or by changing the attribute, and the avatar eases into it.

Grouped options

Flat options and grouped objects are interchangeable; groups are easier to read and write:

```js createBot('#agent', { type: 'cat', preset: 'teddy', fur: { length: 1.6, clumps: 0.6, pattern: 'stripes', color: '#8b5a2b', scale: 1.2 }, light: { angle: 290, color: '#ffe7b3', fill: '#4c6fff', fillStrength: 0.4, rimColor: '#7ad7ff' }, material: { roundness: 0.8, gloss: 0.4 }, face: { eyes: { style: 'oval', iris: '#3b82f6' }, brows: 'soft', mouth: 'cat', freckles: true, expression: 'smug' }, motion: { blinkRate: 1.4, breathing: 1.5, jump: { height: 0.5, spin: 2, squash: 1.3 } }, wear: { hat: 'witch', ears: 'bunny', scarf: true, badge: 'AI', antennae: 'two' }, }); ```

In HTML, groups take JSON. The face group is face-options, because face is the eyes/mouth switch:

```html ``` ::table Group | Options `fur` | `length`, `density`, `fuzz`, `curl`, `gravity`, `clumps`, `pattern`, `color`, `scale` `light` | `angle`, `color`, `fill`, `fillStrength`, `rimColor`, `shadow`, `highlight`, `rim`, `spread` `material` | `shading`, `roundness`, `gloss`, `depth` `face` | `features` (`eyes`/`mouth`), `eyes: { style, size, gap, shine, iris }`, `brows`, `mouth`, `freckles`, `x`, `y`, `scale`, `blush`, `blushColor`, `ink`, `expression` `motion` | `speed`, `turn`, `blinkRate`, `glanceRate`, `breathing`, `jiggle`, `whirl`, `whirlColor`, `jump: { every, height, time, spin, squash, stretch, lean }` `wear` | `hat`, `glasses`, `headphones`, `bowTie`, `color`, `scarf`, `scarfColor`, `badge`, `badgeColor`, `ears`, `antennae`, `accessories` ::end

DNA and identity

Two ways to get a whole look from one string:

```js const code = bot.dna; // 'bot1.…': the whole design, URL-safe createBot('#copy', { dna: code }); // the same bot again createBot('#user', { identity: user.email }); // a stable look of its own for every id ```

Options you pass alongside dna, identity or preset win over theirs. DNA codes are what the studio shares and what crew pages are made of.

CSS variables

<bot-avatar> reads colours from CSS where no attribute sets them: `--bot-color`, `--bot-ink`, `--bot-accessory-color`, `--bot-blush-color`, `--bot-fur-color`, `--bot-light-color`, `--bot-fill-color`, `--bot-rim-color` and `--bot-iris-color`. Call el.refresh() after changing them.

```css .team-red bot-avatar { --bot-color: #ff5c5c; --bot-accessory-color: #2b2833; } ```
