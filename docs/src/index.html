Getting started

bots is one dependency-free ES module that draws plush, animated avatars for AI agents and apps. This page gets one on screen and wired to your agent in about five minutes.

Install

From GitHub, for projects with a bundler. The release branch holds the built package, updated on every change to main:

```sh npm i github:kucukkanat/bots#release ```

Import it as @kucukkanat/bots (and /react, /vue, /svelte, /export, /packs/…). To pin a version, use a commit of that branch: github:kucukkanat/bots#<commit>.

Or straight from a CDN, with no build step at all. The module registers the <bot-avatar> element as soon as it loads:

```html ```

Self-hosting? Copy the src/ folder anywhere your site serves static files. The renderer starts its worker threads from that folder, so keep the files together.

Fourteen shapes ship in the box: `clover`, `flower`, `triangle`, `blob`, `ghost`, `circle`, `drop`, `star`, `droid`, `mech`, `alien`, `hexagon`, `cat` and `cloud`, and a cast of nine creatures with parts and temperaments of their own. The studio shows them all and writes the markup for you.

From JavaScript

createBot() puts an avatar in any element (or a selector) and hands back a controller:

```js import { createBot } from '@kucukkanat/bots'; const bot = createBot('#agent', { type: 'droid', size: 96, glasses: 'round' }); bot.setState('thinking'); // while your agent works bot.set({ hat: 'crown' }); // change anything, it eases in bot.poke(); // hop and turn round bot.destroy(); // remove it and free its canvas ```

The element exposes the same controller as el.bot, and forwards the common methods (el.poke(), el.react(), el.lookAt()…).

Agent states

States are how the avatar tells people what your agent is doing. Switch them as your agent moves through a turn:

::table State | Looks like | Use it when `default` | idle: looks around, blinks, the odd hop | nothing is happening `listening` | leans in, smiles, nods now and then | the user is typing or talking `thinking` | eyes up and aside, a thought bubble | the model is working on a reply `speaking` | mouth moves | the reply is streaming or being read out `working` | busy bouncing | a tool call or long task is running `success` | a happy hop | the task finished `error` | frowns, shakes its head | something failed `sleeping` | eyes closed, Z's | idle for a while ::end

For a full turn wired to a streaming model, see Agent recipes.
