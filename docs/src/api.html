API reference

The module exports a factory, a custom element, a few registration hooks and some constants. Types ship in src/index.d.ts.

createBot()

```js import { createBot } from '@kucukkanat/bots'; const bot = createBot(target, options); ```

target is an element (a canvas is made inside it), a selector string, or a <canvas> to draw into directly. options are the options. It returns a BotAvatar controller; new BotAvatar(target, options) does the same.
