Built for agents

Everything a face needs to feel alive.

Each of these is an option or a method call. Leave one out and it costs nothing: features load on first use.

idle

Agent states

Idle, listening, thinking, speaking, working, success, error, sleeping. A status badge for typing, loading, done.

bot.setState('thinking')

Lip-sync from text

Mouth shapes follow the words, streamed or whole. Or hand it a mic, an audio element or a TTS node.

bot.say(chunk, { append: true })
happy

Moods & reactions

A resting mood, or 'auto' to follow the conversation. Eleven quick reactions on top.

mood: 'auto'
drag · throw · stroke

Toss & pet

Pick it up and throw it, or stroke it with the pointer. Opt in: both are off by default.

{ toss: true, petting: true }

Packs & plugins

Performance

Cheap enough for a whole sidebar of agents.

How it renders →

Drop it in

Five lines, any stack.

<script type="module" src="https://kucukkanat.github.io/bots/dist/bots.js"></script>

<bot-avatar type="clover" state="thinking" size="96"></bot-avatar>
<bot-avatar type="cat" face="mouth" hat="party" mood="happy"></bot-avatar>
import { createBot } from '@kucukkanat/bots';

const bot = createBot('#agent', { type: 'droid', size: 96, status: 'auto' });

bot.setState('thinking');                // while the model works
for await (const chunk of stream) {
  bot.say(chunk, { append: true });      // lip-sync as the answer streams in
}
bot.setState('success');
import { BotAvatar } from '@kucukkanat/bots/react';

export function Agent({ busy }) {
  return <BotAvatar type="clover" state={busy ? 'thinking' : 'default'} size={64} />;
}
<script setup>
import { BotAvatar } from '@kucukkanat/bots/vue';
defineProps({ busy: Boolean });
</script>

<template>
  <BotAvatar type="clover" :state="busy ? 'thinking' : 'default'" :size="64" />
</template>
<script>
  import { bot } from '@kucukkanat/bots/svelte';
  export let busy = false;
</script>

<div use:bot={{ type: 'clover', state: busy ? 'thinking' : 'default', size: 64 }}></div>
